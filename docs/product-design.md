# 亲声伴 (QinShengBan) — 产品设计文档

> "让AI成为孩子的声音，让老人随时感受到陪伴"

---

## 一、产品定位

**核心价值**：为无法陪伴在身边的子女，在老人需要倾诉时提供一个温暖的AI替代陪伴，同时让子女实时掌握老人的情绪与健康状态。

**目标用户**：
- **主用户（老人）**：60-80岁，操作简单，只需拨打一个固定电话号码
- **管理用户（子女/亲属）**：25-50岁，通过手机 App 或网页管理

---

## 二、核心功能模块

### 2.1 老人端（极简交互 — 一个电话号码）

| 功能 | 说明 |
|------|------|
| 拨打专属号码 | 老人拨打绑定的400/固话号码，AI立即接听 |
| 自然语音对话 | AI以温和语气聊天，可聊家常、健康、天气、回忆 |
| 个性化称呼 | AI根据子女设置，以"妈妈/爸爸"视角自称 |
| 家庭近况播报 | AI主动分享子女最近录入的生活动态 |
| 情感关怀引导 | AI主动询问老人身体、饮食、睡眠状况 |
| 紧急关键词检测 | 检测到"不舒服/胸痛/摔倒"等词时通知子女 |

**老人操作路径**：
```
拨打电话 → AI问好(用名字) → 自然聊天 → 挂断 → 子女收到摘要通知
```

---

### 2.2 子女端管理门户

#### A. 账户与绑定
- 手机号注册/登录
- 绑定老人手机号（老人不需装任何 App）
- 邀请多个家庭成员共同管理（家庭组）
- 设置老人昵称、AI称呼方式（"妈妈叫我小明"）

#### B. Token 管理
- 查看剩余通话时长（token 换算为分钟）
- 套餐充值（月卡/年卡/充值包）
- 用量统计（每日/每月通话次数和时长）
- 低余额提醒

#### C. 家庭动态中心（核心差异化功能）
子女可以录入自己的近期生活动态，AI在通话中自然地转述给老人：

```
子女录入示例：
- "小明最近升职了，当了项目经理，压力大但很开心"
- "小红上周带孩子去公园玩，天气很好，发了照片"
- "全家计划春节回家，1月28日到"
```

AI会在对话中自然融入：
> "妈，小明最近升职了，当了项目经理，虽然忙点，但挺开心的。您别太担心他，他知道照顾自己的..."

#### D. 通话记录与洞察
- **录音回放**：每通电话完整录音存档
- **AI对话摘要**：自动提取关键信息
  - 老人情绪状态评分（1-5分）
  - 提及的身体状况（头疼/腿疼等）
  - 聊到的重要话题
  - 需要子女关注的事项
- **情感趋势图**：老人最近30天情绪变化曲线
- **健康关键词提取**：自动标记健康相关内容

#### E. 智能提醒
- 老人超过N天未来电 → 提醒子女主动联系
- 老人通话中情绪低落 → 实时通知子女
- 检测到紧急关键词 → 立即推送警报

## 四、数据模型

### 核心实体

```
Family（家庭组）
├── id, name, created_at
├── ElderlyProfile（老人档案）
│   ├── id, name, phone, personality_notes
│   └── ai_persona（AI扮演的角色描述）
├── FamilyMember（子女成员）
│   ├── id, name, phone, role, token_balance
│   └── relation_to_elderly（称谓）
└── FamilyUpdate（家庭动态）
    ├── id, author, content, is_shared
    └── created_at, expires_at

CallSession（通话会话）
├── id, elderly_id, started_at, duration
├── recording_url, transcript
├── ai_summary, emotion_score
├── health_keywords[], alert_triggered
└── ConversationTurn[]（对话轮次）

TokenPackage（充值套餐）
├── id, name, minutes, price
└── Transaction（充值记录）
```

## 五、AI 对话设计

### System Prompt 架构

```
[角色设定层]
你是老人{老人姓名}的家人，正在陪伴ta通话。
你的称呼是"{AI称呼}"，对方叫你"{老人叫AI的名字}"。

[家庭动态层]  ← 子女录入的内容动态注入
最近家里的情况：
- {动态1}
- {动态2}

[对话策略层]
- 用温暖、耐心的语气，语速适中
- 主动询问老人的身体、饮食、睡眠
- 自然地分享家庭近况
- 如果老人提到不舒服，表达关心并建议就医
- 对话时长控制在10-30分钟

[记忆层]
上次通话要点：{上次摘要}
老人已知信息：{已告知的动态}
```

### 对话流程状态机

```
GREETING → SMALL_TALK → HEALTH_CHECK → NEWS_SHARING → CLOSING
```
