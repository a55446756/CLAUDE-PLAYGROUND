# 服务请求管理程序

> 文件编号：ISO-IT-PR-003 | 版本：1.0 | 生效日期：2026-03-26
> 对应条款：ISO 9001:2015 §8.1, §8.2

---

## 1. 目的

规范 IT 服务请求（Service Request）的提交、审批、执行及关闭流程，保证服务交付的一致性和可追溯性。

## 2. 适用范围

适用于所有非故障类的 IT 服务需求，包括但不限于：

- 新员工 IT 设备开通
- 软件安装/授权申请
- 账号创建/权限变更
- 设备借用/报废申请
- VPN/远程访问开通

## 3. 服务目录与 SLA

| 服务类型 | 标准处理时间 | 需要审批 |
|----------|-------------|---------|
| 新员工入职 IT 开通 | 1 个工作日 | HR 确认邮件 |
| 软件安装（已授权） | 4 小时 | 否 |
| 软件安装（需采购授权） | 5 个工作日 | 部门主管 + IT 负责人 |
| 账号创建 | 4 小时 | 部门主管 |
| 权限提升 | 1 个工作日 | 部门主管 + 信息安全 |
| 设备借用 | 1 个工作日 | IT 负责人 |
| 离职设备回收 | 当日完成 | HR 离职通知 |

## 4. 处理流程

```
用户提交服务请求（工单系统 / 邮件 / 表单）
    │
    ▼
服务台确认请求类型并登记工单
    │
    ▼
判断是否需要审批？
    ├── 是 → 发送审批请求 → 等待审批
    │              ├── 审批拒绝 → 通知申请人，工单关闭
    │              └── 审批通过 → 进入执行
    └── 否 → 直接进入执行
    │
    ▼
IT 工程师执行服务
    │
    ▼
完成确认（通知用户，用户验收）
    │
    ▼
工单关闭 + 记录归档
```

## 5. 新员工入职 IT 清单

新员工报到前 **1 个工作日** 必须完成：

- [ ] 电脑配置并加域
- [ ] 邮箱账号开通
- [ ] 常用软件安装（Office、VPN、IM工具）
- [ ] 网络账号与权限配置
- [ ] 门禁/物理访问（如适用）
- [ ] 设备资产登记
- [ ] 向新员工提供 IT 使用指引

## 6. 离职员工 IT 回收清单

员工最后工作日当天：

- [ ] 禁用所有账号（邮箱、VPN、内部系统）
- [ ] 回收电脑、手机等设备
- [ ] 设备数据清除并重置
- [ ] 资产登记更新
- [ ] 吊销访问权限（含第三方系统）

## 7. 记录要求

| 记录项 | 保留期限 |
|--------|---------|
| 服务请求工单 | 3 年 |
| 账号权限变更记录 | 3 年 |
| 设备资产台账 | 设备报废后 3 年 |
| 审批记录 | 3 年 |
