> 对应条款：ISO 9001:2015 §7.4, §8.1

## 1. 服务台接单标准

### 1.1 接单渠道与响应方式

| 渠道 | 处理方式 | 优先级默认值 |
|------|----------|-------------|
| 电话 | 3 响内接听，立即开单 | P2 |
| 工单系统 | 实时查看，30 分钟内确认 | 按提交内容判断 |
| 邮件 | 每小时巡查，工作时间内回复 | P3 |
| 即时通讯（IM）| 仅用于通知，须在工单系统正式登记 | P3 |

### 1.2 工单必填字段

开单时必须填写以下字段，缺少任何一项为不合规工单：

- [ ] 工单标题（简洁描述问题）
- [ ] 申请人姓名 + 联系方式 + 部门
- [ ] 问题详细描述
- [ ] 优先级
- [ ] 受理工程师

## 2. 常见问题处理步骤

### 2.1 电脑无法开机

1. 确认电源线连接正常
2. 检查电源按钮是否有响应（指示灯/风扇）
3. 强制关机后重新启动
4. 若仍无法开机 → 现场支持，记录为 P2
5. 若涉及数据风险 → 升级至高级工程师

### 2.2 忘记密码 / 账号锁定

1. 核实申请人身份（工号 + 姓名）
2. 通过管理后台重置密码
3. 使用临时密码通知申请人（勿发明文密码至公开渠道）
4. 提醒用户登录后立即修改密码
5. 记录操作时间与操作人

### 2.3 VPN 连接失败

1. 确认用户网络正常（能访问互联网）
2. 检查 VPN 客户端版本是否最新
3. 指导用户重新输入凭据
4. 检查用户账号是否有 VPN 权限
5. 若以上均正常 → 收集日志 → 升级至网络团队

## 3. 升级规则

| 情形 | 升级对象 |
|------|---------|
| 一线处理超过 SLA 50% 时间仍未解决 | 二线支持 |
| 影响 5 人以上的故障 | 主管 + 二线 |
| P1 事件 | 立即通知 IT 负责人 |
| 涉及安全事件（数据泄露/恶意软件）| IT 负责人 + 信息安全 |

## 4. 沟通规范

- **首次回复** 须包含：已收到请求确认、工单号、预计响应时间
- **处理更新** 超过预计时间须主动通知用户进展
- **关单确认** 须得到用户明确回复（"已解决"/"可以关单"）才能关闭工单
- **禁止** 在未解决问题的情况下强制关单

## 5. 下班/假期服务

- 工作时间外的 P1/P2 事件：通过手机通知值班工程师
- 值班轮换表须提前 1 周更新并通知全员
- 节假日前须检查监控告警是否正常运作
