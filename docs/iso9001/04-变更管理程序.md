# 变更管理程序

> 文件编号：ISO-IT-PR-004 | 版本：1.0 | 生效日期：2026-03-26
> 对应条款：ISO 9001:2015 §6.1, §8.1

---

## 1. 目的

通过标准化的审批和测试流程，将 IT 变更（Change）引发的服务中断风险降至最低。

## 2. 适用范围

适用于对生产环境的 IT 基础设施、应用系统、网络、安全策略的所有计划性变更。

## 3. 变更类型

| 类型 | 描述 | 审批要求 | 示例 |
|------|------|----------|------|
| **标准变更** | 低风险、已预批准的例行操作 | 无需额外审批，事后记录 | 密码重置、补丁更新 |
| **普通变更** | 中等风险，需评估和审批 | 变更顾问委员会（CAB）审批 | 服务器配置调整、软件升级 |
| **紧急变更** | 为修复重大事件的紧急操作 | IT 负责人口头批准，事后补文件 | 紧急安全补丁 |

## 4. 变更管理流程

```
变更发起人提交变更申请（RFC）
    │
    ▼
评估变更风险与影响（Risk Assessment）
    │
    ├── 标准变更 → 直接执行 → 事后记录
    │
    ├── 普通变更 → CAB 审批会议（每周一次）
    │                  ├── 拒绝 → 退回申请人
    │                  └── 批准 → 安排变更窗口
    │
    └── 紧急变更 → IT 负责人快速审批 → 立即执行
    │
    ▼
变更实施（含回滚方案准备）
    │
    ▼
变更验证（测试确认服务正常）
    │
    ▼
变更关闭 + 文档更新
```

## 5. 变更申请（RFC）必填内容

- [ ] 变更标题与编号
- [ ] 变更描述（做什么、为什么）
- [ ] 影响范围（受影响系统/用户）
- [ ] 风险评估（低/中/高）
- [ ] 实施步骤（详细操作步骤）
- [ ] **回滚方案**（如变更失败如何恢复）
- [ ] 计划实施时间（建议低峰时段）
- [ ] 测试验证方法
- [ ] 发起人与审批人

## 6. 变更窗口

| 环境 | 建议变更时间 |
|------|------------|
| 生产核心系统 | 周五 22:00 — 周六 06:00 |
| 非核心系统 | 工作日 18:00 — 22:00 |
| 紧急变更 | 任何时间（须通知相关人员）|

## 7. 禁止行为

- 未经审批直接修改生产环境配置
- 在核心业务时间（09:00—18:00）执行高风险变更（紧急变更除外）
- 无回滚方案的变更

## 8. 记录要求

| 记录 | 保留期限 |
|------|---------|
| 变更申请单（RFC）| 3 年 |
| CAB 会议记录 | 3 年 |
| 变更执行日志 | 3 年 |
