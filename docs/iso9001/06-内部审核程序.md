# 内部审核程序

> 文件编号：ISO-IT-PR-006 | 版本：1.0 | 生效日期：2026-03-26
> 对应条款：ISO 9001:2015 §9.2

---

## 1. 目的

通过定期内部审核，验证 QMS 的实施有效性，识别改进机会，为管理评审提供输入。

## 2. 审核频率

| 审核类型 | 频率 | 备注 |
|----------|------|------|
| 全面内审 | 每年至少 1 次 | 覆盖所有适用条款 |
| 专项审核 | 按需 | 重大事件后、流程变更后 |

## 3. 审核员资格

- 内审员须完成 ISO 9001 内审员培训（8 小时以上）
- **审核员不得审核自己负责的工作领域**（独立性原则）

## 4. 审核流程

```
1. 制定年度审核计划（每年 12 月）
       │
       ▼
2. 发出审核通知（审核前至少 2 周）
       │
       ▼
3. 准备审核清单（基于标准条款 + 程序文件）
       │
       ▼
4. 召开首次会议（说明审核目的与安排）
       │
       ▼
5. 现场审核（文件审查 + 访谈 + 记录抽查）
       │
       ▼
6. 审核发现汇总（不符合项 / 观察项）
       │
       ▼
7. 末次会议（宣布发现结果）
       │
       ▼
8. 出具内审报告（审核后 5 个工作日内）
       │
       ▼
9. 跟踪纠正措施（参考程序文件 05）
```

## 5. IT Support 审核重点清单

### 文件与记录（条款 7.5）
- [ ] 程序文件是否为现行有效版本
- [ ] 工单记录是否完整（含时间戳、处理过程、关闭确认）
- [ ] 变更记录是否可追溯

### 服务交付（条款 8）
- [ ] SLA 是否被定期监控
- [ ] 服务请求是否均有工单记录
- [ ] 变更是否均经审批

### 不符合项（条款 10.2）
- [ ] 上次审核的不符合项是否已按时关闭
- [ ] 纠正措施有效性是否经过验证

### 人员能力（条款 7.2）
- [ ] 培训记录是否完整
- [ ] 新员工是否完成上岗培训

### 客户满意度（条款 9.1.2）
- [ ] 是否定期收集用户满意度数据
- [ ] CSAT 是否达到目标值

## 6. 记录要求

| 记录 | 保留期限 |
|------|---------|
| 年度审核计划 | 3 年 |
| 审核通知 | 3 年 |
| 审核清单（含审核结果）| 3 年 |
| 内审报告 | 3 年 |
| 纠正措施跟踪记录 | 3 年 |
