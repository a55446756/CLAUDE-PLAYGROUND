# KPI 与管理评审

## 1. IT Support 质量目标与 KPI

| KPI 指标 | 目标值 | 测量频率 | 数据来源 |
|----------|--------|---------|---------|
| P1 响应率（≤15分钟）| ≥ 95% | 每月 | 工单系统 |
| P2 响应率（≤30分钟）| ≥ 95% | 每月 | 工单系统 |
| 工单按时解决率 | ≥ 90% | 每月 | 工单系统 |
| 首次解决率（FCR）| ≥ 70% | 每月 | 工单系统 |
| 用户满意度（CSAT）| ≥ 4.0 / 5.0 | 每月 | 满意度调查 |
| 调查回复率 | ≥ 30% | 每月 | 满意度调查 |
| 重大事件次数（P1）| ≤ 2 次/季度 | 每季度 | PIR 记录 |
| 不符合项按时关闭率 | 100% | 每季度 | 内审记录 |
| 内审按计划完成 | 100% | 每年 | 审核计划 |

---

## 2. KPI 月度报告结构

每月第 5 个工作日前，IT Support 负责人须完成月度报告，包含：

1. **本月 KPI 汇总表**（对比目标值与实际值）
2. **趋势图**（近 6 个月走势）
3. **未达标项说明**（原因分析 + 改进措施）
4. **重大事件摘要**（本月发生的 P1/P2 事件）
5. **用户投诉摘要**（投诉数量、处理结果）
6. **下月改进计划**

## 3. 管理评审

### 3.1 频率与参与者

| 评审类型 | 频率 | 参与者 |
|----------|------|--------|
| 定期管理评审 | 每年至少 1 次（建议 Q4）| IT 总监、IT Support 负责人、质量管理代表 |
| 季度运营评审 | 每季度 | IT Support 负责人、各团队主管 |

### 3.2 管理评审输入（必须包含）

按 ISO 9001:2015 §9.3.2 要求，管理评审必须评审以下输入：

| 输入项 | 数据来源 |
|--------|---------|
| 上次管理评审行动项完成情况 | 上期评审会议纪要 |
| 相关方（用户）满意度 | CSAT 月报 |
| KPI 达成情况与趋势 | 月度 KPI 报告 |
| 内部审核结果 | 内审报告 |
| 不符合项与纠正措施状态 | NC 记录追踪表 |
| 外部供应商表现 | 供应商评估报告 |
| 过程绩效与服务符合性 | 工单系统数据 |
| 资源充分性评估 | 人员/工具现状 |
| 风险与机遇更新 | 风险登记册 |
| 改进机会 | 各渠道反馈汇总 |

### 3.3 管理评审输出（必须决议）

- 改进机会与行动计划（含责任人、完成日期）
- 资源需求（人员、工具、培训）
- QMS 变更需求（程序文件/目标调整）

## 4. 持续改进来源

| 来源 | 处理方式 | 负责人 |
|------|---------|--------|
| 用户满意度低分（≤2）| 48 小时内主动跟进 | 服务台主管 |
| KPI 连续 2 月未达标 | 启动不符合项流程 | IT Support 负责人 |
| 内审不符合项 | 按 PR-005 处理 | 指定责任人 |
| 员工改进建议 | 季度汇总评审 | IT Support 负责人 |
| 行业最佳实践 | 年度标杆研究 | IT Support 负责人 |
